# Тонкая настройка ИИ в форке

Панель в разделе «Нейросеть» лаунчера и внутри штатной формы **Настройки → Нейросеть → Дополнительно → Тонкая настройка** в партии. Профили привязаны к адресу API и модели; ключи остаются в штатном подключении.

Контекст, максимальный ответ, таймаут, reasoning, verbosity, temperature, top-p, разрешение изображений на вход для Harness и дополнительные параметры JSON. Автоматические значения сохраняют обычные настройки игры. Явно заданные параметры не удаляются молча при отказе API.

## Подключение к форку 0.31.2

1. Добавьте файлы и папку `locales` из [`src/ai/tuning/`](src/ai/tuning/) в одноимённую папку исходного проекта.
2. Примените [`native-ai-tuning-0.31.2.diff`](native-ai-tuning-0.31.2.diff). Он подключает панель в `LauncherCloudAi` и `SettingsScreen`, а профили — в `Provider`, `RequestBuilder` и `RequestGuard`.
3. При отличиях версии объедините изменения с соответствующими методами вашего форка.

Профили сохраняются в отдельном разделе `ai_tuning_profiles` штатных настроек. Лимит ответа учитывается до проверки контекста и остаётся в пределах выделенного запросу бюджета, даже если профиль изменили во время ожидания.

Поддержаны стандартные параметры Chat Completions, Responses, Messages и Gemini. Специальные параметры генерации Ollama требуют отдельного отображения; контекст и автоматический режим доступны.

Эта папка относится к исходникам форка. Устанавливаемый мод находится в отдельном архиве **`ai_tuning-2.4.0.zip`** в Releases.
